# Bus Go - Bus Ticket Booking App

Bus Go is a mobile application built using Flutter, allowing users to conveniently book bus tickets on the go. The app provides a seamless experience for users to search for bus routes, view schedules, select seats, and make hassle-free bookings.

![Flutter](https://img.shields.io/badge/Built%20with-Flutter-02569B?logo=flutter)
![Firebase](https://img.shields.io/badge/Backend-Firebase-FFCA28?logo=firebase)
![License](https://img.shields.io/badge/License-MIT-green)

## Features

- **User Authentication**: Secure user authentication using email/password and Google Sign-In.
- **Ticket Booking**: Search and book bus tickets for various routes.
- **Seat Selection**: Interactive seat selection interface with real-time availability.
- **Payment Integration**: Secure payment processing with multiple gateway options.
- **View Bookings**: Track booking history and manage upcoming trips.
- **Profile Management**: Personalized user profiles with travel preferences.
- **Notifications**: Real-time updates and booking confirmations via push notifications.
- **Offline Support**: Basic functionality available even without internet connection.

## Installation

1. **Clone Repository**:
   ```
   git clone https://github.com/awwsalah/Bus-Ticket-Booking-App.git
   ```
2. **Navigate to Directory**:
   ```
   cd Bus-Ticket-Booking-App
   ```
3. **Install Dependencies**:
   ```
   flutter pub get
   ```
4. **Run Application**:
   ```
   flutter run
   ```

## Technologies Used

- **Flutter**: UI toolkit for building natively compiled applications.
- **Dart**: Programming language optimized for building mobile, desktop, and web apps.
- **Firebase**:
  - **Authentication**: Secure user authentication
  - **Cloud Firestore**: NoSQL database for storing app data
  - **Cloud Storage**: Store and serve user-generated content
  - **Cloud Functions**: Serverless backend code execution
- **Payment Gateways**: Integration with popular payment processors.
- **Google Maps API**: For location-based services and route visualization.
